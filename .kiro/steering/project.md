# Project Steering: Expense & Budget Visualizer

## Project Overview
Expense & Budget Visualizer is a simple web application designed to help users record their daily expenses, manage their budget, and monitor their spending.

## Technology Stack
- HTML5 for website structure.
- CSS3 for styling and responsive layout.
- Vanilla JavaScript for application functionality.
- LocalStorage for saving user data in the browser.

## Project Structure
- `index.html`: Main application page.
- `css/style.css`: Styles and responsive design.
- `js/script.js`: Application logic and interactions.
- `.kiro/steering/project.md`: Project documentation and guidelines.

## Core Features
- Add and manage expense records.
- Set and monitor a budget.
- Calculate total expenses.
- Display budget and spending summaries.
- Save data using browser LocalStorage.

## Development Guidelines
- Use semantic HTML.
- Keep CSS and JavaScript in separate files.
- Use clear and readable code.
- Ensure the application is responsive.
- Use Vanilla JavaScript without additional frameworks.
