
# Expense & Budget Visualizer

## Project Overview
A mobile-friendly web application to help users track daily expenses and visualize spending by category.

## Technology Stack
- HTML for page structure.
- CSS for styling.
- Vanilla JavaScript for functionality.
- Browser Local Storage API for data storage.
- Chart.js for pie chart visualization.

## Required Features
1. Input Form:
   - Item Name
   - Amount
   - Category (Food, Transport, Fun)
   - Validate all fields before submission.

2. Transaction List:
   - Display all transactions.
   - Show item name, amount, and category.
   - Allow users to delete transactions.

3. Total Balance:
   - Display total expenses.
   - Automatically update when transactions are added or deleted.

4. Visual Chart:
   - Display spending distribution using a pie chart.
   - Update automatically when transaction data changes.

## Optional Features
- Custom Categories
- Monthly Summary
- Sort Transactions

## Technical Constraints
- Use HTML, CSS, and Vanilla JavaScript only.
- No frameworks such as React or Vue.
- No backend server.
- Store all data using Local Storage.
- Use only one CSS file inside css/.
- Use only one JavaScript file inside js/.

## Non-Functional Requirements
- Clean and simple interface.
- Responsive design for mobile devices.
- Fast loading and smooth interactions.
- Readable typography and clear visual hierarchy.
