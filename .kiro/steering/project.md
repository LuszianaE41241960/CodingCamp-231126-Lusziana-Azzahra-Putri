# Expense & Budget Visualizer

## Project Overview
Build a mobile-friendly web application called Expense & Budget Visualizer to help users track their daily expenses.

The application displays total balance, transaction history, and spending distribution through a pie chart.

## Technology Stack
- HTML for page structure.
- CSS for styling.
- Vanilla JavaScript for application logic.
- Chart.js for the pie chart.
- Browser Local Storage API for data persistence.
- No frameworks such as React or Vue.
- No backend server.

## Required Features

### 1. Input Form
- Item Name field.
- Amount field.
- Category selection: Food, Transport, Fun.
- Validate that all fields are filled.
- Add transactions when the form is submitted.

### 2. Transaction List
- Display all transactions.
- Show item name, amount, and category.
- Allow users to delete transactions.
- Make the transaction list scrollable.

### 3. Total Balance
- Display total balance at the top.
- Automatically update when transactions are added or deleted.

### 4. Visual Chart
- Display a pie chart showing spending distribution by category.
- Update the chart automatically when transaction data changes.
- Use Chart.js.

### 5. Local Storage
- Save transaction data using browser Local Storage.
- Restore saved transactions when the application is reopened.

## Optional Challenges
Implement these three additional features:
1. Dark and Light Mode Toggle.
2. Monthly Summary View.
3. Sort Transactions by Amount or Category.

## Technical Constraints
- Use only HTML, CSS, and Vanilla JavaScript.
- Only one CSS file inside the css/ directory.
- Only one JavaScript file inside the js/ directory.
- Keep code clean, readable, and organized.
- Ensure compatibility with modern browsers.
- Make the application responsive for mobile and desktop.
